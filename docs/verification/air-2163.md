# AIR-2163 — parser and cache-identity regressions

Based on current main `8e6570c` plus pending producer #81 (`dee2f34`). Coordinated
consumer fix builds on gateway #236 (`2f6ed49`, stage `a65a5bf`). No merge/deploy.

## Reproductions and bounded correction

- QUALIFY `ROW_NUMBER() ... = 1`, `= 2`, and no QUALIFY all previously normalized
  to `SELECT id, ts FROM t`. Complete the pinned AFTER_HAVING modifier dispatch
  and qualify/window/partition/frame methods. Named windows use `AS`, not `OVER`.
- Metadata now rejects generated SQL that reparses to a different argument tree,
  and rejects unsupported-generation warnings. Fault-injection tests deliberately
  make generation return a harmless SELECT; full-input identity survives.
- Generator gaps retain read eligibility, but fallback is SQL-aware: remove ordinary
  comments/normalize gaps and unquoted identifiers only; preserve strings, quoted
  identifiers and binds, including astral Unicode offsets. Reparse fallback too;
  uncertain cases keep raw input. This is not semantic SQL equivalence detection.
- Port COPY dispatch/parameters/credentials/file-location and PIVOT/UNPIVOT parsing
  from the pin. Preserve destination mutation metadata. COPY command fallbacks
  remain UNKNOWN. COPY/PIVOT rendering is still unported, visibly reported.
- Pinned Python also rejects RESTORE. Add a separate **contrib-only Databricks
  extension**, limited to a named table plus literal version/timestamp. Unsupported
  timestamp expressions, bind versions, batches and other dialects remain UNKNOWN.
  [Official syntax](https://docs.databricks.com/aws/en/sql/language-manual/delta-restore)
  is broader than this bounded extension. No invented upstream anchors.

## Clause/statement inventory and limits

WINDOW/QUALIFY roundtrip; PIVOT/UNPIVOT parse, then lexical fallback. SAMPLE/TABLESAMPLE
and CONNECT BY are checked against deliberately lossy generation. MATCH_RECOGNIZE
example remains an explicit parse failure/UNKNOWN, tested rather than silently
excluded. Existing MERGE is structured; OPTIMIZE/VACUUM retain upstream's opaque
Command representation/legacy target extraction. CLONE/DDL paths are not expanded
by this fix. Static metadata is not an SQL authorization system or a proof of UDF
purity. Full-input batching policy and administrator UNKNOWN overrides remain
Michael's AIR-2143 design, unchanged here.

Consumer must pin this producer **and bump cache-key engine e1→e2 together**. That
cold-starts all tenant cache namespaces and avoids old QUALIFY-poisoned entries.
Mixed-version workers still using e1 are not fixed until their code is updated;
rollback must not reuse poisoned e1 data. No production rollout is authorized here.
Gateway boundary tests must check actual cache paths/reuse, target-specific deny,
mutation invalidation and required invalidation failures across Snowflake, Databricks
Thrift and REST. Warehouse/auth/storage response I/O is simulated, not live proof.
Expected UNKNOWN log-severity/rate-limit changes are deferred; deny enforcement stays.
